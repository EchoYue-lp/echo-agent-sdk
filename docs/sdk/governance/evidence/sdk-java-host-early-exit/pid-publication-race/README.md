# Genuine child PID fixture publication race

This is a test-fixture publication race, not an early-exit transport regression: Python `Path.write_text` opens/creates the PID file before writing its contents, while the Java readiness predicate waits only for the file to exist. A reader can therefore parse the empty intermediate file.
