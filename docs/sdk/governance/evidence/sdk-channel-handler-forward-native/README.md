Native stream production stays inside the original reverse callback until all real writes/finally complete. The held-finally case waits the original cancellation signal, then an explicit test release, before returning. It does not spawn detached tasks or count a cancel request as receipt completion. Full-buffer uses real native stream writes and deliberately leaves facade pulls unconsumed. Stop/resource/Session cleanup must cancel before waiting on their permits. Native process assertions refer only to the actual Host process spawned by the public client. Test counters are callback evidence, not OS cleanup or external Run terminal.

Reports use `ECHO_AGENT_SDK_CHANNEL_FORWARD_EVIDENCE`, writing `typescript.json`, `python.json`, and `java.json`. Each report binds real Host binary SHA and relevant source hashes. `compare_channel_forward_results.py` consumes these files after all real tests settle. Missing languages/provenance, incorrect messages/sequences/terminal/counters and invalid requests causing callbacks fail the comparison.
